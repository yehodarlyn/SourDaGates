## Descripción del Proyecto
El objetivo de este avance es diseñar y codificar una plataforma funcional de e-commerce utilizando exclusivamente **HTML5 y CSS3 puro**, sin el uso de frameworks externos como Bootstrap o Tailwind. La aplicación sigue una estructura visual consistente basada en un layout de barra superior, menú lateral, área de contenido y pie de página.

###  Tecnologías Utilizadas
* **HTML5 Semántico:** Uso de etiquetas estructurales, formularios complejos y tablas de datos.
* **CSS3 Moderno:** Implementación de layouts mediante **CSS Grid** y **Flexbox**.
* **Diseño Visual:** Estética *Streetwear* de alto contraste con paleta de colores Negro, Gris y Naranja Neón.

##  Estructura de la Aplicación
La plataforma consta de las siguientes secciones obligatorias:

### Módulo de Cliente
1.  **Inicio (index.html):** Presentación de la marca y datos del desarrollador.
2.  **Registro y Login:** Formularios completos para la creación y acceso de cuentas.
3.  **Catálogo de Productos:** Vista de artículos con filtros por nombre y rango de precios (vía radio buttons).
4.  **Detalles del Producto:** Información técnica, existencias y sección de reseñas de usuarios.
5.  **Flujo de Compra:** Carrito de compras con cálculo de totales, proceso de pago y confirmación de pedido.
6.  **Gestión de Pedidos:** Historial detallado de compras para el usuario.

### Módulo de Administrador
* **Panel de Control:** Enlaces centrales a la gestión del sitio.
* **Gestión de Inventario:** Tablas para crear, editar y eliminar productos.
* **Control de Usuarios:** Administración de estados de cuenta (Activo/Inactivo).
* **Moderación de Reseñas:** Tabla para supervisar y eliminar comentarios de clientes.

##  Requerimientos Técnicos Cumplidos
* **Layout Consistente:** Barra superior con iconos de perfil y salida, menú lateral de navegación y pie de página con el texto "Aplicaciones Web - Unidad 2".
* **Sin Plantillas:** Todo el diseño ha sido codificado manualmente para garantizar la fidelidad al storyboard original de Figma.
* **Interactividad:** Uso de pseudoclases, transiciones y validaciones básicas de formulario.
